页面发布后白屏怎么办？
页面与资源现在部署在同一目录下，使用相对路径引用（如 ./assets/style.css）即可正确加载。白屏通常是因为资源用了绝对路径（如 /assets/style.css）：页面实际运行在 /toy/你的路径/ 下，绝对路径会指向站点根目录而非你的项目。解决方法：将资源引用改为相对路径，或在构建工具中把 base 设为相对路径（如 Vite 设置 base: "./"）。

前端路由应该用哪种模式？
推荐使用 hash 模式（如 Vue Router 的 hash mode）：路由以 #/xxx 形式体现，跳转都在 index.html 内完成，直接访问或刷新都不会 404，兼容性最好。若使用 history 模式，每个路由路径都需对应真实存在的 HTML 文件，否则刷新会 404。普通页面间跳转用相对路径即可（如 ./page2.html）。

发布后为什么不能立即访问？
提交发布后会进入审核流程，审核通过后才会正式上线。你可以在「发布记录」中查看审核状态。

审核状态有哪些？
审核中（等待审核）、已发布（审核通过，已上线）、未通过（审核拒绝，可查看拒绝原因后修改重新提交）、超时（审核超时，可重新提交）。

如何更新已发布的项目？
在「发布记录」中找到对应项目，点击更新按钮（↻），可以重新上传文件、更换封面或修改标题。更新同样需要经过审核。

ZIP 文件有什么要求？
ZIP 包根目录或一级子目录下必须包含 index.html 文件。支持引用相对路径的 CSS、JS、图片等静态资源。

支持哪些文件格式？
上传支持 .zip 压缩包、.html/.htm 单文件、文件夹（会自动打包为 ZIP）。封面支持 .png、.jpg、.jpeg 格式。

ZIP 包内可以包含哪些类型的文件？
出于安全考虑，只有白名单内后缀的文件会被发布，其余文件（如可执行文件、后端脚本）会被自动过滤掉。当前支持的后缀：网页与脚本 .html/.htm/.css/.js/.json/.wasm；数据 .data/.md/.csv/.tsv；图片 .png/.jpg/.jpeg/.gif/.svg/.webp/.ico；字体 .woff2/.woff/.ttf/.eot；音频 .mp3/.wav/.ogg/.m4a；视频 .mp4/.webm；引擎资源 .atlas/.ani/.part/.nani/.unityweb。如果页面依赖被过滤的文件，请改用上述支持的格式或走 CDN 外链。

页面地址（slug）可以修改吗？
发布后页面地址不可修改。如需更换地址，需要删除原项目后重新发布。

发布的内容有大小限制吗？
ZIP 文件建议不超过 20MB。如果项目较大，建议优化图片资源或使用 CDN 外链。

页面内锚点（href="#section"）能用吗？
可以。页面内锚点跳转（如 <a href="#section"> 跳到本页 id="section" 的元素）已支持，点击后会正常滚动定位，无需额外处理。这里说的是「同一个页面内的锚点滚动」，和下一条「用 hash 当路由」是两回事，别混淆：锚点滚动指的是浏览器在当前页面内定位到某个元素；hash 路由指的是用 #/xxx 承载页面级路由。如果你更希望平滑滚动，也可以用 JavaScript 自行实现，例如 document.getElementById("section")?.scrollIntoView({ behavior: "smooth", block: "start" })。

使用 Vue/React 等框架开发，应该上传什么？
只需上传构建产物（如 dist 目录），不要上传源码。先执行构建命令（如 npm run build），然后将生成的 dist 文件夹直接拖拽上传即可。确保 dist 目录下包含 index.html 入口文件。
